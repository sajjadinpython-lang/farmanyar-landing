# فرمانیار — صفحه دمو

صفحه معرفی و دموی افزونه وردپرسی **فرمانیار**؛ دستیار هوش مصنوعی فروشگاه ووکامرس با مدیریت از تلگرام.

## اجرا

فایل `index.html` را در مرورگر باز کنید یا صفحه را روی **GitHub Pages** منتشر کنید:

```bash
Settings → Pages → Branch: main → Save
```

سپس صفحه در آدرس `https://<username>.github.io/farmanyar-landing/` در دسترس است.

## ساختار پروژه

```
├── index.html            # صفحه اصلی دمو
├── style.css             # استایل — تم روشن و تاریک
├── script.js             # تعویض تم، انیمیشن‌ها، fallback تصاویر
└── assets/
    ├── logo.webp         # لوگوی فرمانیار
    ├── logo-small.webp   # نشان کوچک سربرگ
    ├── favicon.png       # آیکون سایت
    ├── providers.webp    # اسکرین‌شات ارائه‌دهنده‌ها
    ├── my-connects.webp  # اسکرین‌شات اتصال‌های من
    ├── chat.webp         # اسکرین‌شات صفحه گفت‌وگو
    ├── telegram.webp     # اسکرین‌شات افزودن ربات تلگرام
    ├── webhook-guide.webp # اسکرین‌شات راهنمای فعال‌سازی وبهوک
    ├── security.webp     # اسکرین‌شات تنظیمات امنیت گفتگو
    └── approvals/        # تصاویر کارت تأیید نمونه دستورها
        ├── command-1.webp
        └── command-2.webp
```

## تصاویر

همهٔ تصاویر مستقیم در `index.html` ارجاع داده شده‌اند و نسبت ابعاد اصلی‌شان حفظ می‌شود
(بدون ویژگی width/height ثابت؛ CSS از `width: 100%` و `height: auto` استفاده می‌کند).

- **کارت‌های تأیید نمونه دستورها:** `assets/approvals/command-1.webp` و `command-2.webp`
- **راهنمای وبهوک:** `assets/webhook-guide.webp` — اگر حذف شود، به‌طور خودکار تصویر
  تنظیمات تلگرام (`telegram.webp`) جایگزین می‌شود.
- برای تعویض هر اسکرین‌شات، کافی است فایل هم‌نامش در پوشه `assets/` را جایگزین کنید.

## امکانات صفحه

- طراحی مینیمال با تم **روشن و تاریک** (مطابق تم افزونه) و ذخیره انتخاب کاربر
- راست‌به‌چپ و کاملاً فارسی با فونت وزیرمتن
- واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- معرفی امکانات، ارائه‌دهنده‌ها، اتصال‌ها، گفت‌وگو، تلگرام (وبهوک و Polling)، امنیت سه‌لایه و نمونه دستورها
