# فرمانیار — صفحه دمو

صفحه معرفی و دموی افزونه وردپرسی **فرمانیار**؛ دستیار هوش مصنوعی فروشگاه ووکامرس با مدیریت از تلگرام.

## اجرا

فایل `index.html` را در مرورگر باز کنید یا صفحه را روی **GitHub Pages** منتشر کنید:

```bash
Settings → Pages → Branch: main → Save
```

سپس صفحه در آدرس `https://<username>.github.io/farmanyar-demo/` در دسترس است.

## ساختار پروژه

```
├── index.html            # صفحه اصلی دمو
├── style.css             # استایل — تم روشن و تاریک
├── script.js             # تعویض تم، انیمیشن‌ها، بارگذاری تصاویر تأیید
└── assets/
    ├── logo.webp         # لوگوی فرمانیار
    ├── logo-small.webp   # نشان کوچک سربرگ
    ├── favicon.png       # آیکون سایت
    ├── providers.webp    # اسکرین‌شات ارائه‌دهنده‌ها
    ├── my-connects.webp  # اسکرین‌شات اتصال‌های من
    ├── chat.webp         # اسکرین‌شات صفحه گفت‌وگو
    ├── telegram.webp     # اسکرین‌شات تنظیمات ربات تلگرام
    ├── security.webp     # اسکرین‌شات لایه‌های امنیتی
    └── approvals/        # ⬅ تصاویر کارت تأیید نمونه دستورها
```

## قرار دادن تصاویر «کارت تأیید» نمونه دستورها

در بخش «نمونه دستورها» دو جای مشخص برای تصویر درخواست‌های تأیید وجود دارد.
تصویر مربوط به هر دستور را با نام زیر در پوشه `assets/approvals/` قرار دهید:

| دستور | نام فایل |
|---|---|
| دستور ۱ — تغییر گروهی قیمت و تخفیف | `command-1.png` |
| دستور ۲ — ساخت کد تخفیف | `command-2.png` |

پسوندهای `png`، `webp`، `jpg`، `jpeg` و `gif` پشتیبانی می‌شوند و به‌ترتیب همین لیست امتحان می‌شوند؛
یعنی `command-1.webp` هم کار می‌کند. تا زمانی که فایل قرار نگرفته باشد، یک راهنمای
جای‌گذاری (Placeholder) نمایش داده می‌شود.

## تصویر بخش «راهنمای فعال‌سازی وبهوک»

تصویر اختصاصی این بخش را با نام `webhook-guide` (با هر یک از پسوندهای `png`، `webp`،
`jpg`، `jpeg`، `gif`) در پوشه `assets/` قرار دهید تا به‌صورت خودکار جایگزین تصویر
پیش‌فرض شود:

```
assets/webhook-guide.png
```

## امکانات صفحه

- طراحی مینیمال با تم **روشن و تاریک** (مطابق تم افزونه) و ذخیره انتخاب کاربر
- راست‌به‌چپ و کاملاً فارسی با فونت وزیرمتن
- واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- معرفی امکانات، ارائه‌دهنده‌ها، اتصال‌ها، گفت‌وگو، تلگرام (وبهوک و Polling)، امنیت سه‌لایه و نمونه دستورها
